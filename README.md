# Fitness Project

## Опис проєкту

Fitness Project — це вебзастосунок для управління фітнес-центром, розроблений на основі Django та Django REST Framework. Система дозволяє адмініструвати тренування, абонементи, платежі та користувачів через зручну адміністративну панель.

Проєкт створений у навчальних цілях як приклад реалізації серверної частини інформаційної системи з використанням сучасних вебтехнологій.

---

## Основні можливості

- авторизація та аутентифікація користувачів;
- керування абонементами;
- керування тренуваннями;
- облік платежів;
- адміністративна панель Django;
- REST API для взаємодії з клієнтською частиною;
- робота з базою даних SQLite.
